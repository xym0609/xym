# 职工管理系统

一个使用 C++ 编写的控制台职工信息管理练习项目，采用面向对象方式组织不同岗位的职工类型，并通过文本文件保存职工数据。

## 当前实现的功能
- 添加职工信息（支持普通职工、经理、老板）
- 显示职工信息
- 按职工编号删除职工
- 修改职工信息
- 按编号或姓名查找职工
- 按职工编号升序或降序排序
- 清空职工数据文件
- 使用文本文件保存和读取数据

## 技术与知识点
- C++ 类与对象、封装、继承和多态
- 基类指针与动态内存管理
- `ifstream` / `ofstream` 文件读写
- 数组与指针
- Visual Studio 项目配置

## 运行环境
- Windows
- Visual Studio（支持当前项目配置的 MSVC 工具集）
- 项目配置使用 C++20

## 如何运行
1. 下载或克隆本仓库。
2. 使用 Visual Studio 打开 `职工管理系统.slnx`。
3. 选择 Debug 或 Release、x64 配置。
4. 生成并运行项目。

程序使用相对路径 `empFile.txt` 保存数据。请确保程序运行时工作目录中存在该文件；项目附带的示例数据文件位于源码目录中，必要时将其复制到程序工作目录。
