## 仓库模板

见 [`repository-templates/`](./repository-templates/)，用于后续创建独立仓库时复用。每个独立仓库都应有自己的 README、构建说明和 `.gitignore`。

## 学习原则

- 重视理解、调试和独立实现，不以提交数量或刷题数量代替能力。
- 只把真实完成、能够解释和复现的内容标记为已完成。
- 主项目优先打磨质量：可构建、可测试、文档清晰、提交记录有意义。
- 练习代码与成熟项目分开展示；不把大量零散代码包装成大型工程。

## 开发环境

- 主要语言：C++
- 当前 IDE：Visual Studio
- CMake 模板默认使用 C++20；具体项目以各自配置为准
