# C++ Learning Notes

可选仓库：只整理自己理解后的笔记、最小示例、实验结论和常见错误。

## 建议分类
- `cpp/`：对象生命周期、RAII、STL、模板、现代 C++。
- `linux/`：进程/线程、文件描述符、系统调用、调试。
- `git/`：分支、合并、冲突处理、Pull Request。
- `build-tools/`：CMake、编译与链接、调试器。

## 笔记标准
每篇笔记尽量包括：要解决的问题、自己的解释、最小代码示例、容易犯错的地方、参考资料和最后验证日期。不要直接复制课程或网站整篇内容。

## 是否需要公开？
不必着急。笔记首先服务于复习；当内容准确、有自己的实验和解释后，再考虑公开。这个仓库不是必须的，也不应挤占主项目和算法训练时间。
