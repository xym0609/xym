# C++ Coursework & Tools

用于整理完成度较高的课程设计、实用小工具和可复用工程模板。零散语法练习继续留在个人学习记录中，不必全部搬进这个仓库。

## 建议目录
- `coursework/`：课程设计与综合实验；每个项目有独立 README、源代码和验证方式。
- `tools/`：真正解决一个小问题的命令行工具或脚本。
- `templates/cmake-cpp/`：最小 CMake + C++20 工程模板。

## 收录标准
- 有明确用途，不只是单个课堂语法片段。
- 能从 README 给出的步骤构建和运行。
- 说明输入、输出、依赖、限制和测试方式。
- 不提交 IDE 缓存、编译产物、个人数据或密钥。

CMake 模板位于 `templates/cmake-cpp/`。它只是最小可构建起点，后续可以按需要增加测试、库、安装规则和 CI。
