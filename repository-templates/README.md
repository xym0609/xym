# 独立仓库起步模板

这里存放未来独立 GitHub 仓库的基础文件和目录约定。

当前可用的 GitHub 连接能直接修改现有仓库文件，但不提供创建新 GitHub 仓库对象的操作。因此这些目前是模板目录，不是四个已经独立创建的仓库。

需要独立发布时，在 GitHub 新建空仓库，再把对应模板目录的内容迁移到新仓库根目录。不要把所有未来仓库长期嵌套在本仓库里。
